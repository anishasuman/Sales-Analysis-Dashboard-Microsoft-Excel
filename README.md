# Excel Sales Analysis Dashboard

## Project Overview
An interactive Microsoft Excel dashboard designed to analyze sales performance, revenue trends, customer spending, and product performance through data visualization and KPI reporting.

## Key Features
- **KPI Metrics:** Total Revenue and Average Customer Spending.
- **Monthly & Hourly Analysis:** Identify sales trends and patterns.
- **Product Analysis:** Top 5 revenue-generating products.
- **City Analysis:** Revenue comparison across the top 10 cities.
- **Occasion Analysis:** Sales performance across different occasions.
- **Day-wise Analysis:** Compare revenue across weekdays.
- **Interactive Filters:** Date timelines and slicers for dynamic analysis.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and Timeline Filters
- Excel Formulas & Functions
- KPI Cards and Dashboard Visualization
